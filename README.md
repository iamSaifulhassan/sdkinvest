# SDK Investing

A Flutter-based mobile investing application designed to help users track stocks, analyze market data, manage portfolios, and build investing knowledge through an integrated learning experience.

> **Project contribution:** Flutter frontend development. This repository documents the mobile application's user-facing experience and the frontend work delivered for the project.

## App Highlights

- **Stock insights:** Stock detail views featuring SDK Score, daily price movement, and six-factor analysis.
- **Portfolio dashboard:** Portfolio value, returns, holdings overview, and sector allocation.
- **Stock comparison:** Side-by-side comparison of selected stocks using key metrics and visual analysis.
- **Alerts and signals:** A unified interface for price alerts, AI-powered signals, and market news.
- **SDK Academy:** Investing courses, tutorials, and educational resources.
- **Subscription plans:** Free, Pro, and Premium plan presentation.
- **Light and dark themes:** Theme options for a consistent experience across the app.

- **Target platform:** Android
- **Development environment:** Visual Studio Code

## Run Locally

### Prerequisites

- Flutter SDK
- Dart SDK
- Android SDK and an Android device or emulator

### Setup

```bash
git clone <repository-url>
cd sdkinvest
flutter pub get
flutter run
```

### Build a Release APK

```bash
flutter build apk --release
```

The APK is generated at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
